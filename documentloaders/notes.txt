1. Company Overview

NovaTech is a fictional software company founded in 2021. Its main
office is in Pune, India. The company builds workflow tools for small
businesses. Its internal motto is “Make routine work simpler.”

NovaTech has three teams: - Product: defines user needs and feature
priorities. - Engineering: builds, tests, and maintains the software. -
Customer Success: helps customers onboard and resolve usage questions.

3. Product Specifications

The NovaDesk product is a web-based task management tool. - Maximum
attachment size: 25 MB per file. - Supported document formats: PDF,
DOCX, TXT, and Markdown. - Default session timeout: 30 minutes of
inactivity. - Search results display up to 8 matches per query. - The
standard backup runs every day at 02:00 UTC. - The default workspace
retention period is 90 days.

NovaDesk does not currently support offline editing. The roadmap
includes calendar synchronization, but no release date has been
confirmed.

5. Support and Troubleshooting

If a document does not appear in search results, first check whether
ingestion completed successfully. If search results look irrelevant,
verify that the question uses the same terminology as the source
document and inspect the retrieved chunks. If a PDF contains scanned
pages, text extraction may require OCR. If an API request returns status
429, the client may have exceeded the configured rate limit. The
recommended response is to wait briefly and retry with exponential
backoff. If an API request returns status 503, the service may be
temporarily unavailable. Check the service status before repeating a
large batch job.

Support hours are Monday to Friday, 09:00–17:00 India Standard Time. The
fictional support email is help@novatech.example.
